# S8.22.7 — Multi-date schedule reliability

Goal: assess date-by-date historical schedule coverage across regular-season, preseason, and no-game candidates, while retaining missing evidence explicitly. Initial five-date manifest is **a test plan**, not five completed comparisons. An independent NBA reference must be acquired and archived per date; no references are bundled or fabricated. Evidence URLs, retrieval timestamps, and raw SHA256 values must be manually verified. Dates with no games require independently documented affirmative evidence, which this first version does not certify. The adapter remains offline; historical snapshots cannot establish pregame availability. Each date's input fingerprint, unmatched games, duplicates, ambiguous mappings and UTC tipoff discrepancies are recorded. All outcomes remain RESEARCH_ONLY / BLOCK_TRAINING.
