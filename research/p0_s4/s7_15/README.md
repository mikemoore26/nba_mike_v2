# S7.15 — Official injury PDF acquisition

Run `python research/p0_s4/s7_15/run_s7_15.py` from project root. The manifest `source_urls.json` lists *candidate* URLs. Existence has **not** been independently verified. HTTP 404s and network failures are recorded in `results/s7_15_acquisition.json` and do not create fake PDFs. Only official NBA host/path URLs are accepted. The script automatically invokes S7.14 on the resulting local PDF collection. To use your own independently verified official links, edit the manifest. Limit: 12 explicit URLs, 12 MB per PDF, 20s request timeout by default. A SHA256-named PDF is stored only if content looks like a complete PDF; S7.14 handles PDF parsing errors. Repeated downloads are deduplicated by bytes. Never commit downloaded PDFs or generated results. Download timestamps do not prove historical publication timestamps. No historical training or bets.
