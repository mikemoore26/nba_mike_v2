# S7.26 — Transaction chronology evidence gate

Run from repository root: `python research/p0_s4/s7_26/run_s7_26.py`. Supply **independently acquired, documented** transaction events in `transaction_evidence.csv`; never manufacture source publication timestamps or SHA hashes. Dates must be ISO; teams must use NBA abbreviations; source URL must be HTTPS; published and retrieval timestamps must be timezone-aware. Events: SIGN, WAIVE, TRADE, RELEASE, CONTRACT_END, TWO_WAY_SIGN, CONVERT, TEN_DAY_SIGN, TEN_DAY_END. `source_document_sha256` must be the hash of the separately retained original document. This milestone does not download or authenticate documents: it validates a transaction evidence ledger and produces an ordered chronology plus a review queue. A same-day disagreement is rejected, and no roster interval is promoted. All results are research-only; source history may be incomplete. Never feed output into S7.23 as VERIFIED. Future: authenticated source capture, player-ID crosswalk, event-sequence gap checks, interval verification and independent publication proof.
