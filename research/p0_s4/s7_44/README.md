# S7.44 — Publication metadata provenance inventory

Run from repository root: `python research/p0_s4/s7_44/run_s7_44.py`.

Inputs: S7.43 review CSV and SHA-256-verified saved HTML objects from S7.38.
Outputs: `results/s7_44_report.json`, `results/s7_44_review.csv`, `results/s7_44_article_inventory.json`.

All extracted timestamps are **unverified, self-reported article metadata**. They do not establish a transaction date or historical publication availability. No promotion to training.
