# S7.31 — Independent origin source excerpt review
Run `python research/p0_s4/s7_31/run_s7_31.py` from the repository root after S7.30. The optional `independent_evidence.csv` must reference locally preserved original independent source snapshots, SHA-256 hashes, and verbatim text excerpts. Empty evidence is valid and yields review candidates and NBA search discovery links; discovery links are NOT evidence. Source excerpts are checked byte-for-byte after UTF-8 decoding; matching names alone does not prove origin or transaction effective date. No records are promoted to S7.26/S7.23. Generated outputs stay untracked.
